# Discord Bot 多功能機器人

一個功能豐富的 Discord 機器人專案，提供新聞聚合、台股資訊、抽籤、天氣查詢、音樂功能、地震監測和反應圖片等多種實用功能。

## 功能特性

- **新聞聚合**：獲取最新焦點新聞和財經新聞
- **股票資訊**：查詢台股指數和個股資訊
- **抽籤功能**：提供淺草抽籤和城隍廟抽籤功能
- **天氣查詢**：獲取當前天氣狀況
- **星座運勢**：提供每日星座運勢預測
- **音樂功能**：基本的音樂播放功能
- **反應圖片**：發送有趣的圖片和表情符號
- **地震監測**：即時監測並通報台灣地區地震資訊
- **自動重啟**：每日自動重啟以確保穩定運行
- **環境變數管理**：使用 `.env` 文件保護敏感資訊

## 技術架構

- 使用 Python 和 Discord.py 庫開發
- 模組化設計，易於擴展
- 使用 Docker 容器化部署
- 緩存機制提高性能
- 完整的錯誤處理和日誌記錄
- 背景任務監測資料更新

## 安裝與設定

### 前置需求

- Python 3.8 或更高版本
- pip 套件管理器
- Discord 開發者帳號與 Bot Token

### 安裝步驟

1. 複製專案
```bash
git clone <repository-url>
cd discord-bot01
```

2. 安裝依賴
```bash
pip install -r requirements.txt
```

3. 配置環境變數
```bash
cp .env.example .env
```
編輯 `.env` 文件，填寫以下必要資訊：
- `DISCORD_TOKEN`：Discord 機器人 Token
- `COMMAND_PREFIX`：指令前綴，預設為 `!`
- `EARTHQUAKE_CHANNEL`：接收地震通知的頻道 ID

4. 啟動機器人
```bash
python main.py
```

### Docker 部署

使用 Docker Compose 快速部署：
```bash
docker-compose up -d
```

## 指令列表

### 抽籤功能
- `!抽籤A`：城隍廟抽籤功能
- `!抽籤B`：淺草寺觀音廟抽籤功能
- `??:問題`：使用淺草籤進行問答

### 新聞
- `!新聞`：獲取最新焦點新聞
- `!財經新聞`：獲取最新財經新聞

### 股票
- `!指數`：獲取台灣加權指數資訊
- `!股票 <股票代碼>`：獲取特定股票資訊

### 天氣
- `!天氣`：獲取當前天氣資訊

### 地震資訊
- `!地震資訊`：獲取最近地震資訊列表

### 星座運勢
- `!今日運勢-<星座>`：查詢特定星座的今日運勢
- `!星座編號`：顯示星座對應編號

### 音樂指令
- `!join`：加入使用者的語音頻道
- `!leave`：離開當前語音頻道

### 娛樂功能
- `!甜味鬆餅`：隨機推薦甜味鬆餅
- `!鹹味鬆餅`：隨機推薦鹹味鬆餅
- `!炸物鬆餅`：隨機推薦炸物鬆餅
- `!鬆餅混搭 甜+鹹`：推薦甜鹹混搭鬆餅
- `!上班`、`!下班`：隨機回覆上下班相關語句
- `!下午茶`：顯示點餐網站連結
